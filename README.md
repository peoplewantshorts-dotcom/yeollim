## 무엇을 하는 앱인가

집을 보러 갔다가 문 앞에서 돌아서는 일을 없애려고 만들었습니다.

1. **당사자** — 휠체어를 타는지, 연락은 어떻게 받고 싶은지만 답합니다. 진단명도 장애 등급도 묻지 않습니다.
2. **앱** — 그 답에서 집이 갖춰야 할 조건을 문헌 근거대로 자동으로 붙입니다.
3. **중개사** — 요청서를 받고 줄자로 몇 군데를 잽니다.
4. **판정** — 갈 수 있어요 / 조금 고치면 돼요 / 가지 마세요.

모르는 값은 절대 추측하지 않습니다. 덜 잰 집은 아직 알려주지 않습니다.

## 무엇을 재는가

| 항목 | 왜 |
|---|---|
| 현관문 폭 | BF 인증심사기준 「출입구 유효폭 0.9m 이상」 |
| 중앙현관 **앞** 계단 · 경사로 | 진입 자체가 막히는 지점 |
| 중앙현관 **안** 계단 (반계단) | **승강기가 있어도 여기서 막히면 못 들어갑니다.** 원룸·빌라에서 가장 흔한 함정 |
| 화장실 문턱 · 문 폭 | 현관을 넘어도 여기서 막히면 혼자 씻지 못합니다 |
| 승강기 · 층 | 2층 이상일 때만 조건이 됩니다 |

## 팀원 피드백 주실 때

무엇이든 좋습니다. 특히 이런 걸 봐주세요.

- **말투** — 어색하거나 기분 상하는 문장이 있는지
- **글씨 크기** — 작아서 안 보이는 곳이 있는지
- **버튼** — 누르기 어렵거나 뭘 하는 버튼인지 모르겠는 곳
- **흐름** — 다음에 뭘 해야 할지 헷갈리는 지점
